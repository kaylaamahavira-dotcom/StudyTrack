# StudyTrack

Aplikasi web pengelola tugas mahasiswa (pengembangan lanjutan proyek ITPM) dengan fitur notifikasi deadline otomatis melalui Email dan WhatsApp pada H-7 dan H-3. Sistem mencatat status pengiriman dan mencegah notifikasi terkirim ganda untuk membantu mahasiswa mengelola tugas dan mengurangi risiko keterlambatan pengumpulan.
